# ToDo CRUD App - Frontend Task

A simple and responsive ToDo application built with HTML, CSS, and Vanilla JavaScript.

### Features
- Create Task (Add new task)
- Read Tasks (Display all tasks)
- Update Task (Edit task with prompt)
- Delete Task (Remove task)
- Mark as Complete (Toggle done)
- LocalStorage (Data stays after refresh)
- Responsive Design
- Task Counter

### Tech Stack
- HTML5
- CSS3 (Flexbox)
- JavaScript (ES6)
- LocalStorage API

### How to Run
1. Clone or download the repo
2. Open index.html in browser
3. No extra setup needed
